## Project Description
A fully responsive, user-friendly web portal designed to provide educational insights and resources on personal financial management, budgeting, investing, and retirement planning.

## Key Features
* **Responsive Layout:** Built using Bootstrap 5 grid layout and custom CSS `@media` query breakpoints for mobile, tablet, and desktop viewports.
* **Interactive Navigation:** Universal dark theme navigation header with responsive mobile hamburger toggle menu.
* **Content Sections:**
  * `index.html`: Home page featuring topic overviews and dynamic responsive card demos.
  * `about.html`: Team member profiles and core organizational values.
  * `blog.html`: Latest articles and an integrated image gallery carousel.
  * `contact.html`: Validated contact form with custom inputs, select options, and inline feedback.
